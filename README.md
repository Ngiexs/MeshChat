# MeshChat

**Peer-to-peer encrypted group chat over Tor.**

MeshChat is a decentralized, peer-to-peer encrypted group chat that runs entirely over the Tor network. No central server, no account, and no phone number required.

## Features

- **End-to-End Encryption:** Messages are encrypted with AES-256-GCM.
- **Tor Network:** All traffic is routed through Tor for anonymity.
- **No Central Server:** Truly peer-to-peer architecture.
- **Automatic Backup Node:** If the host disconnects, a backup node takes over automatically.
- **No Registration:** No email, phone number, or account needed.
